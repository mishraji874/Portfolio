# **App Name**: CodeCraft Portfolio

## Core Features:

- Experience Showcase: Showcase professional experience as a full stack web developer, web3 developer, and smart contract auditor.
- Project Portfolio: Display a portfolio of web development and web3 projects with descriptions and links.
- Contact Form: Allow visitors to easily contact you through a contact form.
- Site Navigation: Provide clear navigation for different sections: Home, About, Projects, Contact.
- Skills Suggester: Offer personalized suggestions to recruiters based on their role and your skillset as highlighted using a smart tool. The AI will determine if the job titles and responsibilities match your skills and will offer to show relevant experience on the portfolio page.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) for a modern, technological feel.
- Background color: Dark navy (#1A2930), a very dark, desaturated version of the primary.
- Accent color: Light violet (#B15DFF) to complement the electric blue.
- Font pairing: 'Space Grotesk' (sans-serif) for headings and short texts; 'Inter' (sans-serif) for body text.
- Use clean, modern icons that align with a development or security theme.
- Design a responsive layout optimized for desktop and mobile devices.
- Incorporate subtle animations on scrolling and project hover to draw interest.
